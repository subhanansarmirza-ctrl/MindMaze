# MindMaze 🧠

A 2D game that teaches C++ Data Structures and Algorithms level by level.

**Creator:** Muhammad Subhan

## Levels
Arrays, Stack, Queue, Bubble Sort, Searching, Recursion, Linked List, Hashing, Trees (BST), Graphs (BFS/DFS), Heap, Dijkstra, Dynamic Programming, Greedy, Backtracking.

## Run
Open `index.html` in any browser. No install needed.
